# CNN 手写数字识别

使用卷积神经网络（CNN）识别 MNIST 数据集中的手写数字 0～9。完整代码、训练记录和可视化单元格见 [CNN手写数字识别.ipynb](CNN手写数字识别.ipynb)。

## 数据集

MNIST 包含 60,000 张训练图片和 10,000 张测试图片。每张图片为 28×28 像素的灰度图，对应一个 0～9 的数字标签。图片像素除以 255，缩放到 0～1，并增加一个灰度通道维度。训练时从训练数据中划出 10% 作为验证集；测试集仅用于训练结束后的评估。

## CNN 结构

| 顺序 | 层 | 作用 |
| --- | --- | --- |
| 1 | Conv2D，32 个 3×3 卷积核，ReLU | 提取局部笔画特征 |
| 2 | MaxPooling2D，2×2 | 缩小特征图 |
| 3 | Conv2D，64 个 3×3 卷积核，ReLU | 提取更复杂的图像特征 |
| 4 | MaxPooling2D，2×2 | 再次缩小特征图 |
| 5 | Flatten + Dense(64)，ReLU | 整合特征 |
| 6 | Dense(10)，Softmax | 输出 10 个数字类别的概率 |

模型共有 121,930 个可训练参数。使用 Adam 优化器和稀疏分类交叉熵损失函数。

## 训练与结果

- 训练轮数：5（`epochs=5`）
- 批量大小：128（`batch_size=128`）
- 验证集比例：训练数据的 10%
- 已保存运行记录中的测试集准确率：**98.79%**

准确率会随重新训练而有小幅变化。仓库中的 98.79% 是笔记本先前运行的输出，并非每次运行的固定结果。
